# ProPePa PEDULI LMS

Platform inovatif untuk mendukung implementasi Kurikulum Merdeka dan Proyek Penguatan Profil Pelajar Pancasila (P5).

## Fitur Utama
- **Siklus PEDULI**: Alur pembelajaran terstruktur (Pelajari, Eksplorasi, Diskusi, Ungkapkan, Lakukan, Introspeksi).
- **Gamifikasi**: Sistem poin dan lencana (badges) untuk memotivasi siswa.
- **Manajemen Konten Dinamis**: Admin dapat mengelola isi materi setiap fase secara real-time.
- **Dashboard Guru**: Monitoring progres siswa, feedback jurnal, dan laporan nilai.
- **Papan Peringkat**: Leaderboard kelas untuk kompetisi positif.

## Teknologi
- Laravel 13
- PHP 8.3
- Tailwind CSS
- MySQL

## Instalasi
1. Clone repositori
2. `composer install`
3. `npm install && npm run build`
4. Konfigurasi `.env`
5. `php artisan migrate --seed`
6. `php artisan storage:link`
