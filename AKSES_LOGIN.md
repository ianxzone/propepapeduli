# 🔑 Data Akses ProPePa LMS

Catatan ini berisi kredensial untuk mencoba seluruh dashboard (Siswa, Guru, Admin).

| Role | Identitas / Email | Password / Kode | URL Login |
| :--- | :--- | :--- | :--- |
| **Siswa** | Pilih Nama (misal: **Budi Darmawan**) | **123456** (Kode Kelas) | `/login` |
| **Dosen / Guru** | `dosen@propepa.id` | `password` | `/guru/login` |
| **Admin** | `admin@propepa.id` | `password` | `/admin/login` |
| **Super Admin** | `superadmin@propepa.id` | `password` | `/admin/login` |

---

### 💡 Petunjuk Pengujian:
1. **Siswa**: Masuk ke `/login`, ketik **123456**, lalu pilih nama siswa.
2. **Guru**: Masuk ke `/guru/login` untuk melihat progres kelas dan memberi feedback.
3. **Admin**: Masuk ke `/admin/login` untuk mengelola modul dan melihat statistik global.

> **Catatan**: Semua password default adalah `password`.
